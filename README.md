# ميزاني — مشروع تطبيق iPhone

تطبيق عربي لإدارة الرصيد والمصروفات والادخار، مع استقبال **رسائل SMS فقط** بواسطة اختصارات Apple. الواجهة SwiftUI، والحد الأدنى iOS 17. التحليل والحساب والتخزين على الهاتف دون خادم أو مفاتيح ذكاء اصطناعي.

## حالة التسليم

هذا **مشروع مصدر أولي قابل للبناء**، وليس تطبيقاً مثبتاً أو ملف IPA موقعاً. نُفذت اختبارات محرك الحسابات على Windows. لا تتوفر في هذه البيئة Xcode أو محاكيات Apple؛ لذلك لم يُتحقق بعد من تجميع Swift أو تشغيل الواجهة والاختصار على iPhone. ملفا GitHub Actions يجهزان التحقق والبناء على macOS.

## الوظائف الموجودة

- واجهة عربية من اليمين إلى اليسار: نظرة عامة، عمليات، خطتي، إعدادات.
- تحليل رسائل بنك مسقط للتحويلات والشراء والاسترجاع والإيداع.
- استخراج المبلغ والحساب والجهة والتاريخ ورقم المعاملة والرصيد.
- منع تكرار الرسائل، دعم حسابات متعددة، ومراجعة الرسائل الناقصة.
- مخصصات للمصاريف والمهام والادخار، وحدود وتنبيهات وإشعارات محلية.
- إضافة يدوية، تصحيح الرصيد، تقارير، CSV، نسخ احتياطية JSON، وقفل اختياري.
- App Intent باسم «تسجيل رسالة بنكية» للاستخدام في Shortcuts.

## التشغيل السحابي

راجع `CLOUD-BUILD-AR.md`. يمكن فحص المشروع على macOS مستضاف في GitHub Actions. لتثبيته عبر TestFlight تحتاج عضوية Apple Developer وإعداد التوقيع وApp Store Connect. لا يلزم جهاز Mac شخصي، لكن حساب المطور أو خدمة البناء قد تكون لهما تكلفة.

## التحقق على Windows

```powershell
npm test
npm run check
node scripts/generate-project.cjs --check
```

## الخصوصية والحدود

المعالجة والتخزين على الهاتف، ولا تُحفظ نصوص الرسائل الخام أو تُرسل العمليات إلى خادم. التطبيق لا يتصل مباشرة بالبنك؛ يعتمد على وصول رسائل SMS عبر Shortcuts، وقد تحتاج قوالب الرسائل الجديدة إلى تحديث المحلل.
